## Этап 5 — Медиа-конвейер ⬜

**Результат:** загрузка через `<Form encType="multipart/form-data">` + `parseFormData` (лимиты 15 MB, ≤ 40 МП, только JPEG/PNG/WebP/AVIF по magic bytes), `sharp`-конвейер (`w480`/`w960`/`w1600` в AVIF + WebP, OG 1200×630 WebP, без EXIF/XMP), blurhash, хеш-имена, `StorageAdapter` (`local`, интерфейс для `s3`), resource route `/media/:hash/:variant`, компонент `ProgressiveImage`, `gc-media`-скрипт.

**Критерии готовности:**

- [ ] JPEG/PNG/WebP/AVIF принимаются; PDF/SVG/GIF и файл с подменённым расширением — отклоняются.
- [ ] Для фото создаётся ровно 6 вариантов + OG; в БД сохранены размеры и blurhash.
- [ ] EXIF (включая GPS) отсутствует в производных (проверка метаданных).
- [ ] Оригинал недоступен по публичному URL; имя файла — хеш.
- [ ] Попытка передать `../` в параметрах маршрута не выходит за каталог хранилища.
- [ ] CLS от изображений = 0 (проверка Lighthouse на демо-странице).

**Оценка:** 2–3 сессии. **Блокеры:** D-022, D-004.
