# DESIGN SYSTEM — EXCELSIO 2.0

**Статус:** предложение (Этап 1). Значения токенов утверждаются владельцем и далее меняются только через PR с записью в `DECISIONS.md`.
**Связанные документы:** `REQUIREMENTS.md` (раздел a11y/перформанс), `ARCHITECTURE.md` (`apps/web/src/styles`).

---

## 1. Визуальная концепция

**Формула:** «тёмная кинематографичная сцена + свет как материал».

- Почти чёрная основа, в которой свет «живёт» пятнами: фиолетовый → синий → коралловый.
- Мягкие, размытые свечения (Black Mist): многослойные радиальные градиенты + шумовая текстура, без «неоновой грязи».
- Крупная типографика с плотным трекингом на заголовках, много воздуха, мало рамок.
- Плавающая капсульная навигация как единственный «хром» интерфейса.
- Ощущение глубины: лёгкий параллакс слоёв, появление элементов при скролле, кинематографичные переходы между секциями.
- Реакция на касание и курсор: мягкое увеличение, магнитные кнопки (только desktop), «дыхание» свечения.

**Ориентиры по ощущению:** Lusion, Cuberto. **Не копировать:** структуру их страниц, анимационные сценарии, шрифты, композицию блоков.

**Принципы:**

1. Свет и движение подчинены контенту, а не наоборот.
2. Один акцент на экран — не три.
3. Ничего не мигает, не дёргается, не блокирует скролл.
4. Деградация вместо поломки: без `backdrop-filter`, AVIF или анимаций сайт остаётся красивым и читаемым.

| Токен | Значение | Использование |
| --- | --- | --- |
| `--ex-bg` | `#08080B` | Основной фон страницы |
| `--ex-bg-deep` | `#050507` | Глубокие секции, футер |
| `--ex-surface` | `#101016` | Карточки, панели |
| `--ex-surface-2` | `#16161F` | Вложенные панели, hover-состояния |
| `--ex-line` | `rgba(255,255,255,0.08)` | Разделители, обводки карточек |
| `--ex-line-strong` | `rgba(255,255,255,0.16)` | Обводка активных элементов |
| `--ex-text` | `#F3F3F7` | Основной текст (контраст к `--ex-bg` ≈ 16:1) |
| `--ex-text-muted` | `#9C9CAD` | Вторичный текст (**не опускать ниже**: контраст ≈ 5.3:1) |
| `--ex-text-dim` | `#6E6E80` | Только декоративные подписи ≥ 18 px/600 |

### 2.2 Акценты

| Токен | Значение | Роль |
| --- | --- | --- |
| `--ex-violet` | `#8B5CF6` | Основной акцент (CTA, активные состояния) |
| `--ex-violet-deep` | `#6D28D9` | Градиенты, тени свечения |
| `--ex-blue` | `#3B82F6` | Второй акцент (ссылки, теги, прогресс) |
| `--ex-blue-deep` | `#1D4ED8` | Градиентные переходы |
| `--ex-coral` | `#FF6B5B` | Третий акцент (акценты-акценты, ошибки-акценты, выделение) |
| `--ex-coral-soft` | `#FF9B8F` | Текст на тёмном, hover |
| `--ex-success` | `#34D399` | Успех (только админка) |
| `--ex-warning` | `#FBBF24` | Предупреждение |
| `--ex-danger` | `#F87171` | Ошибки, удаление |

**Правила использования**

- Градиент-направление: violet → blue по диагонали 135°, coral — точечно, как «искра», а не как второй фон.
- Акцентный текст на тёмном фоне — только `--ex-coral-soft`, `--ex-blue`, `--ex-violet` **на крупном кегле** либо при проверенном контрасте ≥ 4.5:1.
- Запрещены «магические» hex-значения в компонентах: только `var(--ex-*)`.

### 2.3 Свечение и «Black Mist»

Техника (3 слоя, не больше):

1. **Base mist** — `radial-gradient(60% 50% at 50% 0%, rgba(139,92,246,.22), transparent 70%)` за контентом секции.
2. **Flare** — второй радиальный градиент синего/кораллового у края, `opacity .5`, `filter: blur(60px)`.
3. **Grain** — SVG-шум (`feTurbulence`), `opacity: .035`, `mix-blend-mode: overlay`, статичный (без анимации).

Правила: не более **двух** blur-слоёв одновременно на мобильном; `backdrop-filter` — только для капсульной навигации и оверлеев (не более одного на экран); вместо анимации `filter: blur()` анимируется `transform`/`opacity` контейнера (blur-анимации — главный убийца FPS на Android).

## 3. Типографика

### 3.1 Шрифты

| Роль | Шрифт | Причина |
| --- | --- | --- |
| Display (заголовки, цифры) | **Unbounded** (variable, subsets latin + cyrillic) | Выразительные широкие формы с характером, поддержка кириллицы, вариативность по весу |
| Body (текст интерфейса) | **Inter** (variable, latin + cyrillic) | Нейтральный, оптимизирован при мелком кегле, дешёвый по весу |
| Mono (числа, стек, админка) | `ui-monospace`, `JetBrains Mono` при необходимости | Технические подписи |

- Самохостинг woff2 (`/public/fonts`), `font-display: swap`, `preload` только для основного веса body, `size-adjust` для минимизации CLS.
- Альтернатива без отдельного display-шрифта: `Inter Tight` для заголовков (если Unbounded перегрузит композицию) — решение принимается на визуальном прототипе Этапа 9.

### 3.2 Шкала (fluid, `clamp()`)

| Токен | 360–400 px | ≥ 1024 px | Применение |
| --- | --- | --- | --- |
| `--ex-fs-display` | `clamp(2.5rem, 11vw, 4rem)` | `clamp(4rem, 7vw, 7rem)` | Hero: имя, крупный слоган |
| `--ex-fs-h1` | `clamp(2rem, 8.5vw, 2.75rem)` | `clamp(2.75rem, 4.5vw, 4rem)` | Заголовки страниц |
| `--ex-fs-h2` | `1.75rem` | `2.5rem` | Заголовки секций |
| `--ex-fs-h3` | `1.25rem` | `1.5rem` | Карточки, подзаголовки |
| `--ex-fs-body` | `1rem` (16 px) | `1.0625rem` | Основной текст |
| `--ex-fs-sm` | `0.875rem` | `0.9375rem` | Подписи, метаданные |
| `--ex-fs-xs` | `0.75rem` | `0.8125rem` | Теги, надзаголовки (≥ 500 вес) |

Правила: `line-height` — 1.05–1.15 для display, 1.35–1.5 для h2/h3, 1.6 для body; трекинг отрицательный на крупных кеглях (`-0.02em` … `-0.04em`), чуть положительный на `--ex-fs-xs` (`0.08em`, uppercase-надзаголовки); максимальная длина строки — 68 символов (`max-inline-size: 62ch`).

## 5. Сетка и адаптивность (mobile-first)

**Брейкпоинты (только `min-width`):**

| Имя | Значение | Что меняется |
| --- | --- | --- |
| `xs` (база) | `360px` | Одна колонка, крупный кегль, крупные тач-цели |
| `sm` | `400px` | Небольшое увеличение отступов |
| `md` | `480px` | Карточки в 2 колонки (фото — 2, проекты — 1) |
| `lg` | `768px` | Планшет: 2 колонки проектов, 2–3 фото |
| `xl` | `1024px` | Десктоп: 3 колонки, боковые поля, параллакс с параллаксом курсора |
| `2xl` | `1280px` | Максимальная ширина контейнера |
| `3xl` | `1600px` | Атмосферные свечения крупнее, шрифт display на максимуме |

**Правила:**

- Сетка: CSS Grid с `grid-template-columns: repeat(auto-fit, minmax(…))` для галерей; masonry — CSS `columns` (2 на mobile, 3 на планшете, 3–4 на десктопе) с сохранением пропорций через `aspect-ratio`.
- Никаких фиксированных высот у текстовых блоков; галереи — через `aspect-ratio`, чтобы не было CLS.
- `env(safe-area-inset-*)` для капсульной навигации и нижних шитов (Android/iOS).
- Проверка №1 в каждом этапе: **360×640** без горизонтального скролла, всё читаемо, все тач-цели ≥ 44 px.

## 6. Компоненты

Каждый компонент: состояния (default/hover/focus-visible/active/disabled/loading/error), пропсы с типами, без цветов вне токенов.

| Компонент | Описание | Обязательные детали |
| --- | --- | --- |
| `Button` | Варианты: `primary` (градиент violet→blue), `secondary` (обводка), `ghost`, `danger` | Мин. высота 44 px, `aria-busy` при загрузке, ripple/reaction на тач |
| `CapsuleNav` | Плавающая капсульная навигация | `position: fixed` + safe-area, активный пункт — `aria-current`, на 360 px не более 4 пунктов + «меню» |
| `SectionHeading` | Надзаголовок + заголовок + описание | `h2` в разметке, единые отступы |
| `ProjectCard` | Обложка, название, год, стек, теги | `aspect-ratio: 4/3`, hover/тач: масштаб 1.02 + свечение, ссылка — вся карточка |
| `ProjectMeta` | Роль, год, клиент, стек, ссылки | `dl/dt/dd`, ссылки внешние — `rel="noopener"` |
| `PhotoGrid` | Masonry-сетка фотографий | `loading="lazy"` ниже 1-го экрана, `srcset`, blurhash-плейсхолдер |
| `Lightbox` | Полноэкранный просмотр | Фокус-трап, `Esc`, свайп, стрелки, счётчик, кнопка «закрыть», блокировка скролла body |
| `ProgressiveImage` | Плейсхолдер → основной вариант | `width/height` из БД, `decoding="async"`, фейд 200 ms (кроме reduced-motion) |
| `Field` (Input/Textarea/Select) | Формы | `label` связан, ошибка через `aria-describedby`, `aria-invalid` |
| `Chips`/`FilterTabs` | Фильтр категорий | Горизонтальный скролл с градиентной маской, состояние в URL |
| `Dialog` | Модалка/шит | На мобильном — bottom sheet с drag-to-close, фокус-трап, `role="dialog"` |
| `Toast` | Уведомления | `aria-live="polite"`, 4 c, стакается, не перекрывает капсульную навигацию |
| `Skeleton` | Загрузка | Пульсация только `opacity` |
| `Dropzone` | Загрузка медиа (админка) | Прогресс, отмена, ошибки MIME/размера, превью |
| `Table` | Списки в админке | Горизонтальный скролл внутри контейнера, sticky-заголовок, карточный режим на 360 px |

| `GrainOverlay` | Шумовая текстура | Статичная, `pointer-events: none`, `aria-hidden` |
| `ScrollProgress` | Индикатор чтения кейса | `transform: scaleX()`, без layout-триггеров |

## 7. Движение (Motion)

### 7.1 Токены

| Токен | Значение | Где |
| --- | --- | --- |
| `--ex-ease-standard` | `cubic-bezier(.2,.7,.2,1)` | Большинство переходов |
| `--ex-ease-emphasized` | `cubic-bezier(.16,1,.3,1)` | Появление, «кинематографичный» вход |
| `--ex-ease-exit` | `cubic-bezier(.4,0,1,1)` | Уход элементов |
| `--ex-dur-fast` | `120ms` | Наведение, нажатие |
| `--ex-dur-base` | `220ms` | Смена состояний, фокус |
| `--ex-dur-slow` | `420ms` | Открытие шитов, смена секций |
| `--ex-dur-cinematic` | `800ms` | Hero-вход, крупные сцены (только первый экран) |

### 7.2 Правила

1. Анимируются **только** `transform` и `opacity` (плюс `filter` — с оговоркой: не на мобильном).
2. Reveal при скролле — `IntersectionObserver` + CSS-класс; stagger 40–60 ms; без библиотек для базового случая.
3. Параллакс — `translate3d` на 1–2 слоях, амплитуда ≤ 40 px; на мобильном — только hero, и только при отсутствии reduced-motion.
4. Scroll-driven эффекты — CSS `scroll-timeline`, с JS-fallback через Motion `useScroll` (без `useSpring` на длинных страницах).
5. Переходы между страницами — fade + подъём контента на 8–12 px, не дольше 320 ms.
6. `prefers-reduced-motion: reduce`: параллакс и автоплей отключены, reveal → мгновенная видимость, длительности ≤ 120 ms, никаких декоративных циклов.
7. Бюджет: одновременно не более 2 анимируемых «больших» элементов (hero-слои), не более 6 мелких.
8. Проверка: DevTools Performance на профиле «4× CPU throttle», цель — ≥ 50 FPS, отсутствие long tasks > 50 ms в скролле.

## 8. Доступность (обязательные правила системы)

- Контраст текста ≥ 4.5:1, крупного (≥ 24 px/18.66 px bold) ≥ 3:1; UI-границ ≥ 3:1.
- `:focus-visible` — всегда видимый (`--ex-focus-ring`), никогда `outline: none` без замены.
- Тач-цели ≥ 44×44 px, расстояние между смежными ≥ 8 px.
- Иконочные кнопки — `aria-label`; ссылки-иконки — доступное имя.
- Изображения: `alt` обязателен для содержательных, `alt=""` для декоративных (валидация в админке: публикация фото без alt запрещена).
- Порядок заголовков: один `h1` на страницу, без пропусков уровней.
- Диалоги и шиты: фокус-трап, возврат фокуса, `aria-modal`, блокировка фонового скролла.
- Формы: ошибки текстом + `aria-invalid` + `aria-describedby`, статус отправки — `aria-live`.
- Ссылка «Перейти к содержимому» (skip link) — первый фокусируемый элемент.
- Никакой информации только цветом (статусы — цвет + текст/иконка).

## 9. Перформанс-бюджет дизайна

| Метрика | Бюджет |
| --- | --- |
| Blur-слои на мобильном (одновременно) | ≤ 2 |
| `backdrop-filter` на экран | ≤ 1 |
| Шрифтовые файлы | ≤ 4 woff2 (2 семейства × 2 подмножества), суммарно ≤ 200 KB |
| Вес первого экрана Hero (изображение) | ≤ 250 KB (AVIF) |
| Количество изображений без lazy-load | ≤ 8 на страницу |
| JS на публичных страницах | ≤ 180 KB gzip (Home) |
| Анимации, влияющие на layout | 0 |

Деградация: при `navigator.hardwareConcurrency <= 4` или `navigator.deviceMemory <= 4` (где доступно) и при включённой экономии заряда — отключаются необязательные эффекты (cursor glow, тяжёлый parallax, зерно).

## 10. Правила CSS/SCSS

- Структура: `styles/tokens.css` (переменные), `styles/reset.scss`, `styles/base.scss` (типографика), `styles/utils.scss`.
- Компонентные стили — рядом с компонентом, BEM: `.project-card`, `.project-card__media`, `.project-card--featured`.
- Никаких вложенных селекторов глубже 3 уровней; никаких `!important` кроме утилит доступности.
- Миксины: `@include focus-ring`, `@include media-up(md)`, `@include card-surface`, `@include mist($color)`.
- Тёмная тема — единственная в 2.0; светлая не планируется (зафиксировано в `DECISIONS.md`, D-012).
- Пользовательские свойства объявляются в `:root`; компонентные — в блоке компонента через `--_local-*`.

## 11. Контентные правила (тон)

- Короткие фразы, глаголы в действии: «Смотрю», «Строю», «Снимаю» — вместо канцелярита.
- Заголовки — до 6 слов; описания карточек — до 140 символов.
- Фотографии: подпись = место + год + настроение (2–5 слов); alt — описание сцены, не «фото 1».
- В админке — те же правила (это часть контента, а не «технический текст»).
