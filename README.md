# EXCELSIO 2.0

Персональный сайт-портфолио веб-разработчика и фотографа: цифровые проекты, авторская фотография, визуальные эксперименты.

- **Домен (план):** `excelsio-moments.ru`
- **Репозиторий:** [Excelsi0/Excelsio_Moments](https://github.com/Excelsi0/Excelsio_Moments)
- **Основная ветка:** `main`
- **Статус:** Этап 1 — архитектура и документация (кода приложения пока нет)

---

## 1. Что это за проект

EXCELSIO 2.0 — следующая версия личного сайта. Первая версия (`src/`, статический HTML/CSS/JS) была фотопортфолио. Вторая версия расширяет назначение сайта:

1. **Home** — эффектная главная страница.
2. **Development** — каталог веб-проектов.
3. **Project Details** — подробные кейсы.
4. **Photography** — авторская фотогалерея.
5. **About** — информация об авторе.
6. **Contact** — форма связи.
7. **Admin** — защищённая панель администратора (проекты, фотографии, категории, заявки).

Стилистика: премиальное экспериментальное digital-портфолио — почти чёрный фон, фиолетовые/синие/коралловые акценты, кинематографичное мягкое свечение (Black Mist), параллакс, крупная типографика, плавающая капсульная навигация, mobile-first (приоритет 360–400 px).

Ориентиры уровня (не источники копирования): Lusion, Cuberto.

## 3. Текущее состояние репозитория

```
.
├── README.md
├── AGENTS.md
├── .gitignore
├── docs/                 # документация проекта (этот этап)
└── src/                  # версия 1.0: статический сайт-фотопортфолио
    ├── index.html
    ├── css/  js/  icon/  img/
```

**Важно:** каталог `src/` пока содержит первую версию сайта. Он сохраняется как источник контента (фотографии, тексты, иконки, favicon) и как «эталон живого сайта». При старте Этапа 2 (scaffold) он будет перенесён в `legacy/v1/` **отдельным коммитом и только после подтверждения** — см. `docs/DECISIONS.md`, решение D-009.

## 4. Предполагаемый стек (кратко)

Предложение, требующее утверждения на Этапе 2:

- **Frontend:** React 19 + TypeScript (strict) + Vite 7 + SCSS (BEM + CSS-переменные) + Motion для анимаций + React Router 7.
- **Backend:** Node.js (LTS) + Fastify 5 + TypeScript, REST `/api/v1`, Zod-валидация.
- **БД:** PostgreSQL 16+ через Drizzle ORM (альтернатива — SQLite на старте).
- **Изображения:** `sharp` → AVIF/WebP/JPEG-варианты, blurhash-плейсхолдеры, S3-совместимое хранилище или локальный том.
- **Админка:** часть того же React-приложения (route `/admin`), отдельного CMS нет.
- **Деплой:** один VPS + Docker Compose + Caddy (авто-TLS), CI — GitHub Actions.

Подробно и с альтернативами — в [docs/TECH_STACK.md](docs/TECH_STACK.md).

## 5. Принципы

- Mobile-first и производительность на средних Android-устройствах важнее «вау-эффекта любой ценой».
- Никаких секретов в коде: только `.env` (не в git) и GitHub Secrets.
- Простая модульная архитектура без микросервисов.
- Строгая типизация TypeScript, переиспользуемые компоненты.
- Доступность: клавиатурная навигация, контраст, `prefers-reduced-motion`.
- Каждый этап завершается проверкой и осмысленным Git-коммитом.
