# EXCELSIO 2.0

Персональный сайт-портфолио веб-разработчика и фотографа: цифровые проекты, авторская фотография, визуальные эксперименты.

- **Домен (план):** `excelsio-moments.ru`
- **Репозиторий:** [Excelsi0/Excelsio_Moments](https://github.com/Excelsi0/Excelsio_Moments)
- **Основная ветка:** `main`
- **Статус:** Этап 2A — минимальный scaffold приложения (React Router 7 Framework Mode, SSR). Сборка ещё не проверялась: `npm install` и CI — Этап 2B.

---

## 1. Что это за проект

EXCELSIO 2.0 — следующая версия личного сайта. Первая версия (`src/`, статический HTML/CSS/JS) была фотопортфолио. Вторая версия расширяет назначение сайта:

1. **Home** — эффектная главная страница.
2. **Development** — каталог веб-проектов.
3. **Project Details** — подробные кейсы.
4. **Photography** — авторская фотогалерея.
5. **About** — информация об авторе.
6. **Contact** — форма связи.
7. **Admin** — защищённая панель администратора (проекты, фотографии, категории, заявки).

Стилистика: премиальное экспериментальное digital-портфолио — почти чёрный фон, фиолетовые/синие/коралловые акценты, кинематографичное мягкое свечение (Black Mist), параллакс, крупная типографика, плавающая капсульная навигация, mobile-first (приоритет 360–400 px).

Ориентиры уровня (не источники копирования): Lusion, Cuberto.

## 3. Текущее состояние репозитория

```
.
├── README.md
├── AGENTS.md
├── .gitignore
├── docs/                 # документация проекта
├── src/                  # EXCELSIO v1 — рабочий статический сайт, НЕ ИЗМЕНЯЕТСЯ
│   ├── index.html
│   └── css/  js/  icon/  img/
└── apps/
    └── web/              # EXCELSIO 2.0 (появится на Этапе 2)
```

**Важно:** каталог `src/` содержит первую версию сайта. По решению владельца он **не перемещается и не изменяется** (см. `docs/DECISIONS.md`, D-021). Новая версия будет жить в `apps/web/` со своим `package.json` и каталогом `app/`, поэтому старая и новая структуры не конфликтуют. GitHub Pages для репозитория не включён — публикация v1 идёт не из этого репозитория и от этих изменений не зависит.

## 4. Предполагаемый стек (кратко)

Предложение после ревизии Этапа 1.5, требующее утверждения (подробно — в `docs/TECH_STACK.md`):

- **Одно приложение:** React Router 7.18.x Framework Mode (SSR) + React 19 + TypeScript (strict) + Vite + SCSS (BEM + CSS-переменные) + Motion.
- **Серверная часть** — там же: `loader`/`action`, resource routes, БД-сессии, обработка загрузок (`sharp`), Telegram-уведомления.
- **БД:** SQLite (WAL) + Drizzle ORM; PostgreSQL — путь роста с отдельной оценкой работ.
- **Изображения:** 3 ширины × AVIF/WebP + OG-вариант, blurhash, локальное хранилище с адаптером под S3.
- **Расположение:** единственный пакет `apps/web/`, без монорепо и workspaces.
- **Проверки:** GitHub Actions (Node 24) — `typecheck`, `lint`, `test`, `build`.
- **Деплой:** один VPS + Caddy (авто-TLS) + systemd/Docker; CI — GitHub Actions.
- **Отклонено на Этапе 1.5:** Fastify, отдельный REST API, npm workspaces, TanStack Query, react-hook-form, обязательный PostgreSQL, 18 вариантов изображений.

## 5. Принципы

- Mobile-first и производительность на средних Android-устройствах важнее «вау-эффекта любой ценой».
- Никаких секретов в коде: только `.env` (не в git) и GitHub Secrets.
- Простая модульная архитектура без микросервисов.
- Строгая типизация TypeScript, переиспользуемые компоненты.
- Доступность: клавиатурная навигация, контраст, `prefers-reduced-motion`.
- Каждый этап завершается проверкой и осмысленным Git-коммитом.

## 6. Локальный запуск

Приложение находится в `apps/web/`. Зависимости пока не установлены и `package-lock.json` не сгенерирован (Этап 2B):

```bash
cd apps/web
npm install        # создаст package-lock.json (делает владелец или CI)
npm run dev        # SSR dev-сервер
npm run build      # production-сборка (build/client + build/server)
npm run start      # запуск собранного приложения
npm run typecheck  # react-router typegen + tsc
```

Скрипты `lint` и `test` появятся вместе с ESLint и Vitest. В среде Android/Acode сборка и проверки выполняются в **GitHub Actions** (агент не имеет shell-инструмента), см. `docs/DECISIONS.md`, D-023. **Фактический запуск и сборка пока не проверены.**
